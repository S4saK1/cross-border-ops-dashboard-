# 跨境产品资料中英对照系统 - 用户手册

## 系统概述

跨境产品资料中英对照系统是专为跨境卖家设计的产品资料一致性管理系统。它帮助卖家维护产品参数的中英文对照关系，确保在全球电商平台上的产品资料准确、一致、专业。

## 主要功能

### 1. 用户管理
- **用户注册**：创建新用户账户
- **用户登录**：使用邮箱和密码登录系统
- **角色权限**：支持admin、editor、reviewer、viewer四种角色
- **用户管理**：管理员可以管理所有用户账户

### 2. 产品管理
- **产品创建**：添加新产品信息
- **产品编辑**：更新产品详细信息
- **产品删除**：删除不需要的产品
- **产品搜索**：按关键词、分类等搜索产品
- **产品分类**：管理产品分类体系

### 3. 术语词典
- **术语管理**：维护专业术语的中英文对照
- **术语分类**：按类别组织术语
- **术语搜索**：快速查找术语
- **术语导入**：批量导入术语数据

### 4. 一致性检测
- **自动检测**：检测产品参数与术语词典的一致性
- **问题报告**：生成一致性问题报告
- **修复建议**：提供修复建议和批量更新

### 5. 数据导入导出
- **CSV导入**：批量导入产品数据
- **CSV导出**：导出产品数据为CSV格式
- **模板下载**：下载数据导入模板

### 6. 审计日志
- **操作记录**：记录所有系统操作
- **用户行为**：追踪用户操作历史
- **系统变更**：记录系统配置变更

## 用户角色说明

### 管理员（admin）
- 完全访问权限
- 用户管理权限
- 系统配置权限
- 数据删除权限

### 编辑者（editor）
- 产品和术语的创建、编辑权限
- 数据导入权限
- 一致性检测权限
- 无用户管理权限

### 审核者（reviewer）
- 产品和术语的查看权限
- 数据导出权限
- 一致性检测查看权限
- 无编辑权限

### 查看者（viewer）
- 只读权限
- 可以查看所有数据
- 无编辑或删除权限

## 使用指南

### 登录系统
1. 访问系统主页：http://localhost:3000
2. 输入邮箱和密码
3. 点击"登录"按钮

### 添加产品
1. 导航到"产品管理"页面
2. 点击"添加产品"按钮
3. 填写产品信息（必填：SKU、中文名称、英文名称、品类）
4. 保存产品信息

### 管理术语词典
1. 导航到"术语词典"页面
2. 点击"添加术语"按钮
3. 填写术语信息（必填：中文、英文、分类）
4. 保存术语

### 批量导入数据
1. 准备CSV格式的数据文件
2. 导航到"批量导入"页面
3. 上传CSV文件
4. 预览导入数据
5. 确认导入

### 导出数据
1. 选择需要导出的产品
2. 点击"导出"按钮
3. 选择导出平台（Amazon/Alibaba）
4. 下载CSV文件

### 查看一致性检测
1. 导航到"一致性检测"页面
2. 点击"开始检测"按钮
3. 查看检测结果和问题报告
4. 根据建议修复问题

## 数据格式说明

### 产品数据格式
| 字段名 | 中文名称 | 必填 | 说明 |
|--------|----------|------|------|
| sku | SKU | 是 | 产品唯一标识 |
| product_name_zh | 中文名称 | 是 | 产品中文名称 |
| product_name_en | 英文名称 | 是 | 产品英文名称 |
| category | 品类 | 是 | 产品分类 |
| brand | 品牌 | 否 | 产品品牌 |
| description_zh | 中文描述 | 否 | 产品中文描述 |
| description_en | 英文描述 | 否 | 产品英文描述 |
| price | 价格 | 否 | 产品价格 |
| currency | 货币 | 否 | 货币单位，默认USD |
| stock | 库存 | 否 | 产品库存数量 |
| color_zh | 中文颜色 | 否 | 产品颜色中文 |
| color_en | 英文颜色 | 否 | 产品颜色英文 |
| material_zh | 中文材质 | 否 | 产品材质中文 |
| material_en | 英文材质 | 否 | 产品材质英文 |
| size | 尺寸 | 否 | 产品尺寸 |
| weight | 重量 | 否 | 产品重量 |
| weight_unit | 重量单位 | 否 | 重量单位，默认kg |
| origin | 产地 | 否 | 产品产地 |
| model_number | 型号 | 否 | 产品型号 |

### 术语数据格式
| 字段名 | 中文名称 | 必填 | 说明 |
|--------|----------|------|------|
| zh | 中文 | 是 | 术语中文 |
| en | 英文 | 是 | 术语英文 |
| category | 分类 | 是 | 术语分类 |
| note | 备注 | 否 | 术语备注 |
| synonyms | 同义词 | 否 | 术语同义词 |
| platform_amazon | Amazon平台术语 | 否 | Amazon平台对应术语 |
| platform_alibaba | 阿里巴巴平台术语 | 否 | 阿里巴巴平台对应术语 |

## 常见问题解答

### Q: 如何重置密码？
A: 请联系管理员重置密码。

### Q: 如何批量导入产品？
A: 准备CSV文件，导航到"批量导入"页面，上传文件并按照向导操作。

### Q: 如何导出产品数据？
A: 选择需要导出的产品，点击"导出"按钮，选择平台并下载CSV文件。

### Q: 如何查看操作日志？
A: 导航到"审计日志"页面，可以查看所有系统操作记录。

### Q: 如何修改用户角色？
A: 管理员可以导航到"用户管理"页面，编辑用户角色信息。
