## 技术决策记录

### ADR-001: PostgreSQL数据库迁移路径
- **决策**: 采用多数据库支持方案（SQLite + PostgreSQL）
- **理由**: 
  - 开发体验优先：SQLite零配置特性保持开发效率
  - 生产就绪：PostgreSQL提供生产环境所需的所有特性
  - 渐进式迁移：允许团队逐步适应生产数据库
- **实施计划**: 4个阶段，预计6-8周完成
